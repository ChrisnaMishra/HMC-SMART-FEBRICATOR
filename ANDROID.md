# HMC Smart Fabricator — Android Java

Native Android Studio project for Hulas Metal Crafts Ltd.

- Language: Java
- UI: Android XML + Material
- Application ID: com.hulas.hmc
- Current branch: android-java-rebuild
- HULAS logo and existing product imagery are reused from the original repository.
- Calculator uses the current HMC master round-pipe values for 202/304 and 6m pipe weights.
- QR scanning is implemented as a scanner entry point; production point awarding must be server-verified.
- Login in this foundation is local only and is intentionally not treated as production authentication.

Open the repository root in Android Studio and sync Gradle.
